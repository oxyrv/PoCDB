# PoCDB
A simple local CVE PoC search engine to populate yourself!

# How to run
1. ```chmod +x ./start_server.sh && ./start_server.sh```

3. Open "index.html"
4. Done!

# How to populate
1. Add PoC as zip files in the DB folder
2. Add a preview of its code as txt in the same folder
3. Make sure to name those with a specific number (the same for both)
4. Edit DB/db.json to add the new PoC
5. Restart the server
6. Done!
